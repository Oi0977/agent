## 1. 一张全景:RAG 两条线

```
【离线·建库】build_index —— 只需跑一次

  PDF 文件
      │
      ▼
  ① parse_document()      文档解析 …… 详解见《01-文档解析》
      │
      ▼
  ② smart_chunk_text()    文本分块 …… 详解见《02-文本分块》
      │
      ▼
  ③ embed_texts()         向量嵌入 …… 详解见《03-向量嵌入》
      │
      ▼
  ④ FAISS 落盘            建库 …… 详解见《04-向量检索》
      │                     .index(向量) + .json(原文+元数据)
      ▼
【在线·问答】rag_answer —— 每次提问都跑

  用户问题
      │
      ▼
  ⑤ embed_query()         问题嵌入(加BGE前缀) …… 《03》
      │
      ▼
  ⑥ hybrid_search()       混合粗排:向量+BM25 两路,RRF 融合 top-20 …… 《04》
      │
      ▼
  ⑦ rerank()              精排:交叉编码器精选 top-3 …… 《05-重排序》
      │
      ▼
  ⑧ build_prompt()        拼装:资料+问题 → prompt …… 《06-LLM生成》
      │
      ▼
  ⑨ chat()                生成:智谱 GLM-4.7-flash …… 《06》
```

**两条线的交汇点**是向量库产物(`data/output/` 下的 `.index` + `.json`):
离线生产它们,在线消费它们。

## 2. 模块职责速查

| 模块 | 职责 | 对外接口 | 详解 |
|------|------|----------|------|
| `preprocessor/` | 各格式文档 → 纯文本 | `parse_document(path) → str` | 01 |
| `chunker/` | 长文本 → 块列表 | `smart_chunk_text(text, size, overlap) → list[str]` | 02 |
| `embedder/` | 文本 → 512维向量 | `embed_texts()` / `embed_query()` | 03 |
| `retriever/` | 建库 + 粗排检索(向量单路/混合两路) | `build_index()` / `search()` / `hybrid_search()` | 04 |
| `reranker/` | 精排重排序 | `rerank(query, hits, top_k)` | 05 |
| `generator/` | prompt 拼装 + LLM 调用 + 全链路 | `rag_answer()` | 06 |

## 3. 全局设计哲学

**① 裸函数,不上重型框架。** 全项目唯一引入的 langchain 组件是 `langchain-text-splitters`
(分块)。检索用裸 FAISS、生成用裸 OpenAI SDK——目标是看清每个机制(FAISS 只存向量、
id 映射、BGE 前缀),而这些恰恰是框架会藏起来的东西。框架(LangChain/LangGraph)
留给 Agent 化阶段再评估,那时已手写过一版,能看懂框架在解决什么。

**② 每个流水线阶段一个包。** `preprocessor/chunker/embedder/retriever/reranker/generator`
一一对应数据流环节,职责单一,`__init__.py` 薄门面只暴露公开接口。

**③ 模型资产本地化。** 两个本地模型(BGE 嵌入 + BGE 重排)统一缓存在
`S:\huggingface_cache`,代码直接解析本地快照目录加载,彻底离线(详见《03》)。

**④ LLM 生成走远程 API,薄抽象可换。** 当前智谱 GLM-4.7-flash(免费);
换本地 Ollama 只改 `llm_client.py` 顶部两行(详见《06》)。

## 4. 业界产品对照(2026 调研)

| 维度 | 本项目 | Dify | RAGFlow | FastGPT | MaxKB |
|---|---|---|---|---|---|
| 定位 | 学习项目(裸机制) | LLM 应用开发平台 | 深度文档理解 RAG 引擎 | Flow 可视化平台 | 企业知识库 |
| 后端 | 纯 Python 裸函数 | Flask + Celery | Python + Elasticsearch | Node.js | Django + Vue |
| 文档解析 | pdfplumber + RapidOCR | Unstructured | DeepDoc(OCR+版面+表格识别) | 内置多策略 | 内置+手动分段 |
| 向量库 | FAISS(文件级) | Weaviate/Qdrant 等 | Elasticsearch | MongoDB+向量插件 | pgvector |
| 检索策略 | 混合(向量+BM25+RRF)+精排 | 向量+全文+混合+Rerank | 向量+全文+混合 | 混合 | 混合 |
| Rerank | ✅ bge-reranker-base | ✅ | ✅ | ✅ | ✅ |
| Agent 能力 | 无(下一阶段) | Workflow 编排 | Agent 模式 | Flow 编排 | 工作流 |
