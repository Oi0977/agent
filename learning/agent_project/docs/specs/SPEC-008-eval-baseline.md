# SPEC-008 轻量评测基线

- **编号**: SPEC-008
- **类型**: 功能 · 影响面: 独立(新增评测资产与脚本,不改核心代码)
- **状态**: ✔ 已验收(2026-08-19)
- **创建**: 2026-08-19
- **关联**: SPEC-002(混合检索)、SPEC-001(两段式)、详解 05(重排实证)

## 背景

项目所有效果论断都是轶事证据("pcapng 那次混合检索 10/10")。要支撑"混合检索
优于纯向量""精排有正向作用"这类简历级论断,需要**可重复的数字**。本 spec 建
最小评测资产:金标问题集 + 检索指标脚本,产出三种配置的基线对比表
(纯向量 / 混合 / 混合+精排)。它也是后续任何改动(换模型/上 LangGraph)
的回归标尺。

## 目标 / 非目标(MoSCoW)

**Must**:
- 金标集 `tests/eval/golden.json`:≥15 题,每题
  `{"id", "question", "keywords": [应命中的关键词列表], "type": "literal|semantic"}`
  (关键词判据:命中块的原文含关键词 → 视为相关块;比 chunk_id 稳健,重建库不失效)
- 评测脚本 `tests/eval_retrieval.py` 可重复运行,对三配置计算:
  - **hit@k**:top-k 内存在相关块的问题占比(k=3,与线上 rag_answer 一致)
  - **MRR**:首个相关块排名倒数的均值
- 输出基线表:每题明细 + 汇总(三配置 × 两指标),并打印"混合较纯向量的提升幅度"
- 脚本依赖已入库文档,跑前检查并提示 ingest

**Should**:
- LLM-as-judge:`tests/eval_answer.py` 对 rag_answer 输出按
  忠实度/相关性 1-5 打分(走现有智谱 API),产出答案质量均分
- 按题型(literal/semantic)分桶汇总——验证"字面题混合强、语义题不退步"

**Won't**:
- RAGAS 等评测框架;大规模题集(≥100);人工标注流程;A/B 统计显著性

## 验收标准(Given-When-Then)

- [x] AC1 — 金标集格式(离线)
  - Given golden.json
  - Then ≥15 题、字段齐全、type 合法、keywords 非空(脚本自校验)

- [x] AC2 — 指标正确性(离线,构造用例)
  - Given 人造 ranking([无关, 相关, 无关]) 
  - When 计算 hit@3 与 MRR
  - Then hit@3=1.0、MRR=0.5(手算可验);指标函数纯逻辑可单测

- [x] AC3 — 三配置基线(真机,本地模型)
  - When python tests/eval_retrieval.py
  - Then 输出三配置 hit@3/MRR 表;确定性(同库重跑数字一致);
    **混合 hit@3 ≥ 纯向量**(literal 题集上严格不劣)

- [x] AC4 — 基线归档(文档)
  - Then 汇总数字回填本 spec 实现备注 + README 路线图(可引用的量化论断)

- [x] AC5 — Should:LLM 打分(真机 API)
  - When python tests/eval_answer.py --limit 5
  - Then 对 5 题答案输出 1-5 分及均分(429 由退避兜底)

## 涉及模块

## 风险与兜底

- **金标准确性**:由 AI 依据已验证的检索行为构造关键词,首版接受"AI 标注"
  性质,题集入库后可人工修订(记录于实现备注)
- **语料覆盖**:Wireshark 单书,15+ 题从已有验收用例扩展(HTTPS 解密/pcapng/
  过滤器/着色/统计等),可行性已验证
- **LLM judge 波动**:temperature=0.1 固定;分数仅作参考维度,不与检索指标混排名

## 实现备注(实现后回填)

### 基线数字(2026-08-19,16 题,双文档库 465+3 块,k=3)

| 配置 | hit@3 | MRR | literal 桶 hit@3 |
|---|---|---|---|
| 纯向量(跨库按余弦合并) | 75.0% | 0.604 | 89% |
| 混合(D+1 路 RRF) | 75.0% | 0.604 | **100%** |
| 混合 + cross-encoder 精排 | 75.0% | **0.688** | 89% |

**可引用论断**:字面题混合检索 hit@3 100% vs 纯向量 89%(+11pt,严格不劣→严格更优);
精排把 MRR 从 0.604 提到 0.688(首位命中率提升)。语义桶混合 43% < 向量 57%
(q11 类无字面线索题被常见词词法匹配稀释)—— 已知取舍,如实记录。

### 评测驱动的两轮检索修复(本 spec 最大产出)

1. **首跑暴露**:裸 RRF 混合 hit@3 仅 56%,反低于纯向量 75% —— SPEC-005 记录的
   "小文档名次压缩"在无精排路径现形(q01 pcapng 被 3 块小笔记挤出 top-3)
2. **第一次修(向量路 0.35 地板)无效**:诊断显示小库块余弦 0.38-0.44,地板不咬合
3. **诊断定位真因**:rank_bm25 的 IDF 是库内统计 —— 小库 0.09 分噪音匹配拿满
   "第1名",与大库 13.2 分的第1名在 RRF 同权,弱匹配双路双计反压真结果
4. **第二次修(全局 BM25)**:合并全部文档块统一建词法索引(IDF 全局化)→
   混合 56%→75%,literal 78%→**100%**。向量分同模型天然跨库可比维持分路;
   BM25 分不跨库可比必须全局(SPEC-005 修订记录 ×2,04 详解 §9 同步)
- **确定性**:评测前后多次运行数字逐题一致(FAISS 精确检索 + cross-encoder 无随机)
